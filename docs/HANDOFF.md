# 프로젝트 인수인계 보고서

마지막 갱신: 2026-07-30

## 한 줄 요약

이 프로젝트는 **솔리테어처럼 여러 파일에 쌓인 카드를 조작하면서 싸우고, 무한 평면처럼 보이는 그리드 지도를 탐험하는 싱글 플레이 웹게임 프로토타입**이다.

현재는 전투, 지도, 덱 케이스, 덱 편집, 전투 보상, 상점, 소모품까지 한 브라우저 안에서 동작한다. 다음 큰 작업은 **지역에 따라 다양한 적을 추가하고 적 시스템을 확장하는 것**이다.

## 지금 어디까지 동작하는가

- 지도에서 인접한 8방향의 방을 클릭해 한 칸씩 이동할 수 있고, 지나온 길은 자동 이동할 수 있다.
- 기존 `?` 방과 고정 전투 방은 빈칸으로 바뀌었다.
- 적은 별도 오버맵 개체이며, 플레이어 이동 뒤 9×9 활성 범위 안에서 상태에 따라 움직인다. 적 정보는 플레이어 중심 가로 5칸 × 세로 3칸의 15칸 안에서만 보이며, 자동 이동은 적을 발견하면 멈춘다.
- 플레이어나 적이 상대 칸으로 들어가면 전투가 시작되며, 특수 칸에서는 전투가 우선된다.
- 전투가 시작되면 덱이 5장씩 파일에 배치되고, 각 파일 맨 위 카드를 손으로 가져온다.
- 카드 사용, 파일 간 묶음 이동, 손패에서 파일로 이동, 별 자원이 동작한다.
- 전투가 끝나면 지도 방 바닥에 카드·소모품·덱 케이스 보상이 남을 수 있다.
- 덱 편집, 덱 보기, 상점, 회복 노드, 안전 지역, 포탈이 동작한다.
- `main` 브랜치에 push하면 GitHub Pages 자동 배포를 시도한다.

## 기술 상태

|---|---|
| 언어 | TypeScript, CSS |

| 로컬 개발 실행기 | Vinext/Vite |

가장 큰 기술 부채는 지도, 전투, 드래그, 보상, 덱 편집 화면이 거의 모두 `app/page.tsx` 하나에 들어 있다는 점이다. 새 적을 소수 추가하는 것은 그대로도 가능하지만, 적이 계속 늘어날 예정이라면 먼저 적 데이터와 전투 규칙을 별도 파일로 나누는 편이 안전하다.

## 현재 작업: 하수구 적 시스템

기존 테스트 적 두 마리는 삭제되었다. 하수구에는 단독 적 네 조합과 하수구 쥐 네 마리 조합이 있다.

- 가고일 석상
- 독성 점액
- 하수구 뱀
- 청소부
- 하수구 쥐 네 마리

적 데이터와 행동 선택 함수는 `app/game/enemies.ts`에 분리되어 있다. 행동이 여러 개인 적은 직전 행동을 가능한 한 연속해서 사용하지 않는다. 복합 공격, 다단 공격, 적 힘, 단단함, 재빠름, 다음 공격 마법화를 지원한다. 열정과 각성 시스템은 사용자 결정으로 삭제된 상태를 유지한다.

오버맵 적의 생성·L∞ 거리·`Zzz/?/!` 상태 변화·8방향 이동은 `app/game/mapEnemies.ts`에 분리되어 있다. 새 탐험을 시작할 때 전체 지도 적 배치가 미리 확정된다. 적 스폰율은 현재 7%이며, 최초 시작 칸과 그 주변 8칸에는 적이 스폰되지 않는다. 모든 상태 변화는 해당 적의 행동 한 번을 소모한다.

## 확인된 불일치와 주의점

- 사용자는 과거에 `예비`를 “2장 뽑고 2장 버리기”로 바꾸자고 요청했지만, 현재 코드는 여전히 **1장 뽑고 1장 버리기**다. 다음에 카드 정리 작업을 할 때 의도를 다시 확인해야 한다.
- README에 남아 있던 “각성 패턴” 표현은 오래된 설명이라 이번 문서 작업에서 제거했다.
- 게임 상태를 저장하지 않으므로 새로고침하면 진행이 초기화된다.
- 맵은 큰 유한 배열로 만들지만, 플레이어에게는 넓은 평면처럼 보이게 설계되어 있다.
- 최근 GitHub Pages 실행 일부는 GitHub runner의 `startup_failure`로 실패했다. 로컬 빌드 성공 여부와 공개 사이트 반영 여부를 따로 확인해야 한다.

## 안전한 다음 개발 순서

2. 적이 상점·포탈 위로 이동했을 때 전투가 먼저 시작되는지 확인한다.
3. 가고일의 단단함과 독성 점액의 다음 공격 마법화를 직접 확인한다.
4. 네 마리 전투의 가로 스크롤과 록온 사용성을 확인한다.
5. 다음 지역의 이름과 적 풀은 사용자와 합의한 뒤 추가한다.
